1. Download ZIP File
2. Extract Files
3. Open `index.html`
4. Explore Portfolio Website

## Deploy on GitHub Pages

1. Push Code to GitHub
2. Go to Repository Settings
3. Enable GitHub Pages
4. Select Main Branch
5. Save Changes
